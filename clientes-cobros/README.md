# Clientes y Cobros — Cubo SEO

Herramienta interna de gestión de clientes, servicios y pagos.

- **Aplicación activa:** [clientes.cuboseo.com](https://clientes.cuboseo.com/), alojada en HostGator con PHP y MySQL.
- **Este repositorio:** código fuente y documentación. GitHub Pages no ejecuta PHP y no es el servidor de la aplicación.
- **Datos:** los registros reales, respaldos y credenciales permanecen fuera de este repositorio público.
- **Conexión desde ChatGPT:** la integración directa/MCP sigue pendiente; el objetivo es trabajar sin una API de OpenAI de pago.

## Estado del código

El directorio queda ubicado en el repositorio principal de Cubo SEO. Falta importar una copia limpia del código que corresponde a la versión activa. La copia local disponible contiene instrucciones de preinstalación y no se debe tratar como la fuente vigente.

Al sincronizar el código, usar un paquete solo de archivos de aplicación. No incluir configuración de producción, contraseñas, claves de instalación, bases SQL con datos, exportaciones ni respaldos.

## Estructura esperada

El código PHP/MySQL se organizará aquí por carpetas públicas, privadas y scripts. Mantén la configuración privada fuera de la raíz pública del subdominio y fuera de GitHub.
